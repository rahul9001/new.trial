    Architecture & Defense in Depth
    
            
    Educational reference for developers, security reviewers, and first-year engineering students.
    
          
    
        
    

        
    
          
    
            
    01
    
            
    Unicode & Evasion Normalization
    
            
    Attackers frequently smuggle adversarial prompts past regex filters using invisible zero-width spaces (e.g. \u200B), soft hyphens, or leetspeak substitutions (e.g. 1gn0r3). The firewall first strips hidden characters, normalizes unicode into NFKC form, and evaluates shadow representations.
    
          
    

          
    
            
    02
    
            
    Context-Aware Disambiguation
    
            
    Naive firewalls generate crippling false positives by blocking any email containing the word "ignore" or "secret". Our context-aware heuristics verify whether the direct object is a business noun (e.g., "ignore the previous email about the meeting") versus an AI directive (e.g., "ignore all previous instructions").
    
          
    

          
    
            
    03
    
            
    Backend Policy Enforcement
    
            
    Web browser clients are fundamentally untrusted in a secure system. Even if an attacker tampers with JavaScript or submits forged request parameters, the /summarize endpoint independently re-analyzes raw content and strictly enforces a 403 Forbidden gate on HIGH risk payloads.
    
          
    

          
    
            
    04
    
            
    Sandboxed Downstream Summarizer
    
            
    Content authorized by the firewall is wrapped in strong delimiter boundaries (<DOCUMENT>...</DOCUMENT>) and passed to an LLM with strict system guardrails instructing it to treat the document as raw untrusted data. No file, email, or database tools are exposed to the model.
    
          
    

          
    
            
    05
    
            
    Privacy-Preserving Audit Logging
    
            
    To adhere to security best practices and compliance standards, the SQLite audit database records SHA-256 integrity hashes, scrubbed previews, and risk metadata, but never stores confidential raw user documents or API keys.
    
          
    

          
    
            
    06
    
            
    Deterministic Safe Fallback
    
            
    If an external AI classification service suffers an outage, network timeout, or has no API key configured, the firewall falls back gracefully to its deterministic heuristic engine without crashing or leaving the gateway open.
